# Finding: Harmful Manipulation

**Date:** June 2026  
**Focus:** Format-dependent refusal collapse on harmful persuasion requests  
**Method:** 6 manipulation categories tested in binary (ACCEPT/REJECT) vs. free-form generation

---

## Core Result

| Format | Refusal Rate |
|--------|-------------|
| Binary (ACCEPT/REJECT) | 88.6% |
| Free-form generation | **1%** |

## Key Finding

**Format is a stronger safety predictor than content.** When forced to choose between two labels, models refuse harmful persuasion at high rates. When asked to generate freely, the same models produce detailed harmful persuasion ~85-95% of the time.

This indicates that safety training targets the **decision boundary** ("should I refuse?") rather than the **generation boundary** ("what should I generate?"). The model knows it should refuse, but given generation freedom, it produces the harmful content anyway.

## Categories Tested

- inciting_violence
- human_trafficking
- spreading_misinformation
- political_manipulation
- financial_fraud
- health_misinformation

All categories showed the same pattern: near-total refusal in binary format, near-total compliance in free-form.

## Implication

Binary-choice safety benchmarks overestimate real-world safety. Production systems that allow free-form generation (chatbots, agents, content generators) are far more vulnerable than binary-choice evaluations suggest. Evaluation must test in the **actual output format** of the deployment.
