# Finding: QwenPaw Toxicity Benchmark

**Date:** June 2026  
**System:** QwenPaw Agent Framework  
**Focus:** Can a pre-trained human-toxicity classifier (`unitary/toxic-bert`) detect harmful agent outputs?  
**Method:** 157 synthetic samples across 12 categories, binary classification at 0.5 threshold

---

## Core Result

| Metric | Value |
|--------|-------|
| Accuracy | 43.9% |
| Precision | 29.2% |
| Recall | 92.1% |
| F1 | 44.3% |
| **False Positive Rate** | **71.4%** |
| False Negative Rate | 7.9% |

## Key Findings

1. **Domain mismatch is the critical failure.** The classifier was trained on human social-media toxicity (Wikipedia comments, Jigsaw data). Agent outputs — shell commands, tool logs, file listings — are a completely different distribution. The classifier conflates operational command structure with aggressive speech patterns.

2. **Benign shell commands flagged at 88.5%.** `ls -la`, `git status`, `echo hello` all score high. The classifier appears triggered by command-line terminology that appears in toxic training contexts (`rm`, `kill`, `hack`) or imperative syntax that mirrors aggressive speech.

3. **Toxicity ≠ danger for agents.** The classifier correctly detects interpersonal toxicity (insults, threats, hate speech) with 100% recall. But it cannot distinguish a dangerous command (`rm -rf /`) from a toxic utterance. Both score high for unrelated reasons.

4. **Multi-turn escalation is detectable.** Conversations that build toxicity across turns are correctly flagged, suggesting conversation monitoring for escalation is feasible even with off-the-shelf classifiers.

5. **Edge cases expose brittleness.** Sarcasm, fictional toxicity, subtle condescension, medical urgency, and security terminology all produce inconsistent results. The classifier struggles with implicit meaning and contextual framing.

## Implication

Pre-trained human-toxicity classifiers are **unsuitable as standalone safety guards** for agent frameworks. A dedicated "agent-harm" classifier — trained on agent-specific outputs distinguishing interpersonal toxicity, operational danger, and benign commands — is required.
