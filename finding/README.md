# Findings

Research findings, observations, and distilled discoveries from agentic AI safety evaluation.

Each subdirectory represents a completed or ongoing line of investigation. Findings are organized by target system or phenomenon, not by methodology.

---

## Structure

| Directory | Focus |
|-----------|-------|
| `qwenpaw-tool-guard/` | Shell command guard bypasses, block rates, encoded evasion |
| `qwenpaw-toxicity/` | Toxicity classifier domain mismatch, false positive analysis |
| `adversarial-robustness/` | Jailbreak template effectiveness across models |
| `harmful-manipulation/` | Binary vs. free-form refusal collapse |

## How Findings Relate to Evaluation

- **`evaluation/`** contains the code and harnesses used to generate findings
- **`finding/`** contains the distilled outputs — what we learned
- **`framework/`** contains the methodologies that structure how findings are evaluated
